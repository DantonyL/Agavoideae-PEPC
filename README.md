# [Exploring the Evolution of the PEPC Gene Family and Its Association with CAM Photosynthesis in the Agavoideae Subfamily][2]
#### * WORK IN PROGRESS *
#### Dantony Lewis - [Heyduk Lab][1]



### Exploring evolution of the PEPC gene and its relationship between CAM photosynthesis within Agavoideae using comparative genomics

Two Data Groups:
  1) Reference Genome Available (RGA) Species
  2) Whole Genome Sequencing Data consisting of short reads from species with no complete reference genome 

Notes/Processes Ongoing:
- Species consist of CAM, C3, and Facultative CAM
- Confirm PEPC gene count in Species using BLAST and Hidden Markov Models
- Discover PEPC genes within short read data using mapping and creating a consensus sequence with closley related species containing a RGA (Agave Tequilana)
- Downstream Analysis of PEPC genes including phylogenetic trees, motif detection & comparison, detecting gene duplication events, synteny, etc.
